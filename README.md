# Personal Savings Tracker

A responsive savings tracker application that helps users create financial goals, track deposits, monitor progress, and visualize monthly savings through an interactive chart.

Built as a Frontend Mentor project using vanilla HTML, CSS, and JavaScript.

## 🚀 Features

- Create new savings goals
- Edit existing goals
- Delete goals
- Add deposits
- View deposit history
- Automatic progress tracking
- Monthly deposits chart
- Filter goals
- Sort goals
- Persistent data using Local Storage
- Responsive design for desktop, tablet, and mobile

## 💡 What I Learned

This project helped me become more comfortable working with JavaScript to build a complete application instead of small isolated features.

Some concepts I practiced include:

- Working with arrays using `map()`, `filter()`, `find()`, `reduce()`, and `forEach()`
- Rendering dynamic HTML using template literals
- Managing application state with Local Storage
- Creating reusable helper functions
- Building responsive layouts with CSS Grid and Flexbox
- Manipulating the DOM with JavaScript
- Updating UI components dynamically after data changes
